## 写作风格

### 开头习惯
- [ ] 场景切入："上周我遇到一件事..."
- [ ] 反常识判断："所有人都在吹XX，但我觉得..."
- [ ] 具体数字："XX天，XX星，XX用户"
- [ ] 提问引入："你有没有想过..."

### 段落习惯
- [ ] 短段落为主（1-3行）
- [ ] 中等段落（3-5行）
- [ ] 长短交错

### 观点表达
- [ ] 敢下判断（"我认为三年内XX会消失"）
- [ ] 敢说反话（"所有人都在吹XX，但我觉得大多数人搞错了方向"）
- [ ] 温和理性（"我不确定，但我觉得..."）

### 术语使用
- [ ] 尽量通俗化
- [ ] 适度使用并解释
- [ ] 默认读者有专业背景
