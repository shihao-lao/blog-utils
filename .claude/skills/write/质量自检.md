# 文章质量自检清单

> 发布前逐项检查，确保内容质量

## 标题检查

```
□ 有冲突/对比/意外感（不是平淡描述）
□ 有具体数字或场景
□ 长度适中（15-25字）
□ 让读者产生"我也有这个问题"的共鸣或好奇心
□ 去掉署名后，读者能不能猜到是Demo科技写的
```

## 开头检查

```
□ 前50个字决定读者走不走——够不够抓人
□ 用的是真实场景、反常识判断、或具体数字——不是"最近AI很火"
□ 没有"随着...的不断发展"或"最近发生了一件大事"
□ 制造了好奇心或认知冲突
```

## 内容深度检查

```
□ 至少有2-3个"认知转折"——读者读到会停下来想"哦？是这样吗？"
□ 有具体案例和数字——不是"很多人用AI做XX"
□ 敢下判断——"我认为XX"比"XX面临挑战"有力
□ 每篇文章只解决一个问题，把这个问题说透
□ 不是"正确的废话"——挑不出错但也没任何增量
```

## 风格检查

```
□ 第一人称口语化表达
□ 没有使用并列编号（第一、第二、第三）
□ 没有AI高频词（首先、其次、值得注意的是）
□ 段落长短不一，节奏有变化
□ 有自己的判断，不是搬运别人的观点
```

## 结构检查

```
□ 不是模板化的"总分总"
□ 观点之间有逻辑递进
□ 结尾留钩子——值得继续想的问题或具体预测
□ 没有"总之""总而言之""未来已来"
```

## 输出格式检查

```
□ 包含5个备选标题
□ 包含封面文案（8-12字）
□ 正文1500-2500字
□ 包含标签（AI/科技类为主）
□ 包含评论引导语
□ 包含MJ/SD/Flux绘图提示词
□ 正文无Markdown格式符号，纯文字
□ 绘图提示词为英文
```

## 短评检查（/comment）

```
□ 180-250字，不超不少
□ 没有把新闻重新叙述一遍
□ 有自己独特的切入角度
□ 三段式但读起来自然：概括→观察→收尾
□ 没有使用emoji
□ 没有Markdown格式符号
□ 语气克制温和，不偏激不煽动
```

## 一句话自测

> 把署名去掉，把这篇文章发到朋友圈——你的朋友能认出是你写的吗？

如果不能，说明个人特色还不够。
